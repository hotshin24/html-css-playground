# HTML/CSS 학습 플레이그라운드 — 1단계 구현 요청

## 프로젝트 개요

사용자가 등록한 웹 디자인 시안을 보고 직접 HTML/CSS를 작성하며 **시맨틱 마크업**과 **레이아웃 구현**을 훈련하는 학습 도구입니다.

이번 단계에서는 **학습 화면의 UI 골격과 에디터, 실시간 미리보기까지** 구현합니다. AI 분석과 판정 로직은 다음 단계이므로 이번엔 포함하지 않습니다.

상세 사양은 `docs/PRD_HTMLCSS_Playground_v0.3.md` 를 참조해 주세요.

## 현재 상태

- Next.js 16 (App Router) + TypeScript + Tailwind CSS v4
- 루트 `app/` 디렉터리 사용 (`src/` 미사용)
- import alias `@/*` → `./*` 설정됨
- 아직 기본 스캐폴딩 상태

## 이번 단계 범위

### 포함

1. 학습 화면 3분할 레이아웃
2. CodeMirror 6 기반 HTML/CSS 에디터
3. iframe sandbox 실시간 미리보기
4. 에디터 설정 토글
5. 작성 코드 및 설정 자동 저장

### 제외 (다음 단계)

- AI 분석
- 판정 로직
- 소스 등록 화면
- 구역 편집 화면
- 피드백 패널의 실제 내용 (자리만 잡아둘 것)

## 1. 화면 레이아웃

```
┌────────────────────────────────────────────────────────┐
│  [구역 2/5 · 히어로]         시도 2/3    [설정] [확인]   │  상단 바
├──────────────┬──────────────────┬──────────────────────┤
│              │  HTML            │                      │
│   시안       │                  │     결과 화면        │
│   이미지     ├──────────────────┤     (실시간)         │
│              │  CSS             │                      │
│              │                  │                      │
├──────────────┴──────────────────┴──────────────────────┤
│  채점 피드백                              [접기/펴기]   │  하단 패널
└────────────────────────────────────────────────────────┘
```

### 요구사항

- 3개 열의 너비를 경계선 드래그로 조절 가능
- 2열 내부 HTML/CSS 영역의 높이 비율을 드래그로 조절 가능
- 하단 피드백 패널은 접기/펴기 가능, 기본 접힘
- 조절한 비율은 저장하여 재방문 시 복원

### 이번 단계의 더미 데이터

- 1열 시안 이미지: `public/` 에 임시 이미지를 두고 표시
- 상단 바의 구역/시도 표시: 하드코딩된 값
- 확인 버튼: 비활성 상태
- 하단 패널: "판정 결과가 여기에 표시됩니다" 정도의 자리 표시

## 2. 에디터 (CodeMirror 6)

### 기본 요구사항

- HTML 에디터(상단), CSS 에디터(하단)
- 각 에디터 Y축 스크롤
- 문법 하이라이팅
- 자동 들여쓰기
- 닫는 태그 자동 생성
- 괄호·따옴표 자동 짝맞춤
- undo / redo

### 자동완성 제어 (이 프로젝트의 핵심 학습 장치)

자동완성을 두 그룹으로 분리하여 한쪽만 토글 가능해야 합니다.

| 기능 | 출처 | 제어 |
|---|---|---|
| 태그 이름 제안 (`n` → `nav`) | `autocompletion()` | **토글 대상** |
| HTML 속성 이름·값 제안 (`cl` → `class`) | `autocompletion()` | **토글 대상** |
| CSS 속성명 제안 (`disp` → `display`) | `autocompletion()` | **토글 대상** |
| CSS 값 제안 (`display:` → `flex`) | `autocompletion()` | **토글 대상** |
| 닫는 태그 자동 생성 | `html({ autoCloseTags })` | 항상 활성 |
| 괄호·따옴표 짝맞춤 | `closeBrackets()` | 항상 활성 |

**기본값은 토글 대상 전체가 꺼짐입니다.** 학습자가 태그와 속성 이름을 직접 떠올리는 것이 훈련의 핵심입니다. 특히 `alt`, `aria-label` 같은 접근성 속성을 자동 제시하는 것은 시맨틱 훈련을 저해하므로 속성 제안도 토글 대상에 포함합니다.

**구현 방식**

토글 대상은 전부 `autocompletion()` 에서 발생하고, 항상 활성 대상은 별개 확장입니다. 따라서 완성 소스를 개별 필터링(`override`)하지 말고, **`autocompletion()` 확장 자체를 Compartment로 넣고 빼는 방식**으로 구현해 주세요. 언어 패키지가 등록하는 완성 소스의 내부 표현에 의존하지 않아 버전 변경에 안정적입니다.

`basicSetup` 은 사용하지 마세요. `autocompletion()` 을 강제 포함하여 위 요구사항과 충돌합니다. 확장을 직접 조립해 주세요.

`@uiw/react-codemirror` 도 사용하지 마세요. Compartment 재설정을 직접 제어해야 하므로 `EditorView` 를 직접 생성하는 얇은 래퍼로 구현합니다.

### 설정 UI

상단 바의 설정 버튼으로 여는 패널에 다음 토글을 둡니다.

## 3. 미리보기

- 사용자가 작성한 HTML/CSS를 iframe에 렌더링
- `srcdoc` 에 `<!doctype html>` 부터 직접 조립하여 주입
- `sandbox=""` (allow-scripts 미부여 → 스크립트 차단)
- 리셋 CSS를 주입하지 않아 사용자가 작성한 CSS만 적용
- 부모 페이지의 Tailwind가 iframe 내부에 영향을 주지 않아야 함
- 타이핑 정지 후 약 300ms 뒤 자동 갱신 (디바운스)
- iframe 자체는 재마운트하지 않고 `srcdoc` 만 갱신

---

## 4. 자동 저장

저장 대상은 다음 세 가지입니다.

| 대상 | 비고 |
|---|---|
| 작성한 HTML/CSS | 디바운스 처리 |
| 에디터 설정 | 이름 제안, 줄바꿈 토글 |
| 레이아웃 비율 | 열 너비, HTML/CSS 높이 비율 |

1단계 저장소는 localStorage를 사용합니다.

## 5. 구현 방향

### 폴더 구조 제안

```
app/            layout.tsx, page.tsx, globals.css
components/
  layout/       WorkspaceLayout, ColumnResizer, RowResizer, TopBar, FeedbackPanel
  editor/       CodeEditor, EditorPane, SettingsPopover
  preview/      PreviewFrame
lib/
  editor/       extensions.ts, compartments.ts, theme.ts
  storage/      localDriver.ts, settingsStore.ts, draftStore.ts, layoutStore.ts
  constants.ts  더미 데이터, 저장 키
```

### 데이터 접근 계층 분리 (중요)

저장소 접근은 `lib/storage/` 안에만 두고, 컴포넌트에서 직접 호출하지 않도록 해주세요.

향후 IndexedDB, 이후 Supabase로 교체할 계획입니다. localStorage는 동기 API지만 IndexedDB와 Supabase는 비동기이므로, **저장 계층의 인터페이스를 처음부터 Promise 반환으로 통일**해 주세요. 복원은 마운트 후 실행하여 하이드레이션 불일치를 방지합니다.

### 코딩 규칙

- TypeScript 사용
- Tailwind CSS 사용
- 함수형 컴포넌트 + Hooks
- 주석은 한국어
